# Episode 04 · The hover taxi

One concept image, four agents, and a rule: I don't build anything myself. I only talk to agents and review what they give me back. The taxi goes from a chat image to clean references, to a model in Blender, to a hovering, flying vehicle in Unreal.

**Video:** <link once published>

## The briefs, in the order they appear

1. [Reference coverage check](01-reference-coverage.md): before modelling, find out what the concept image actually shows and what the agent would have to invent.
2. [Clean reference set](02-clean-reference-set.md): six consistent orthographic views to build from, instead of pretty pictures that disagree with each other.
3. [Stage switcher](03-stage-switcher.md): record how an Unreal scene grew, one key per stage, without touching the original map.
4. [Hover idle](04-hover-idle.md): make a hovering vehicle feel alive, with a controller instead of a toy bob.

More from this episode may follow (the departure flight, the lighting fix).
